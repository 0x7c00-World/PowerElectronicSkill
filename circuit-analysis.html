电路与系统分析：在电力电子里怎么用

网络定理 · 拉普拉斯变换 · 模拟电子 · 数字电子 —— 从一张电路图到一段可量产的 DSP 代码

基础层 01 先修：微积分、线性代数、电路 产出：Gvd(s) → 补偿器 → 差分方程 含完整算例

这一层不是知识，是翻译器。它不直接产出设计，但决定你能否把一张开关电路图翻译成能在纸上解的方程。翻译不出来的人，只能靠试错和抄参考设计；翻译得出来的人，能在打板之前就知道环路会不会振荡、带宽能推到多高。

电力电子的麻烦在于开关器件是非线性的、时变的，所以把整个变换器当成一个线性时不变系统、直接套传递函数和 Bode 分析这一步不成立。注意别把话说满：KCL / KVL 永远成立，开关状态固定的子区间配合理想器件模型本来就是线性电路，真正失效的只是"整机 LTI 化"这个动作。行业里有一套固定的四步套路，把非线性问题一步步拉回线性世界——网络定理负责前两步，拉普拉斯负责后两步，模电和数电负责把结论变成硬件和代码。这份文档就是按这条主线组织的。

严格结论

知识依赖关系

下面这张图是全文的骨架。四个知识块各自负责流水线上的一段，右侧是每一段的产物。看的时候注意：每一段的输出都是下一段的输入，跳步一定会出错。

四步套路详解

这套流程是 Erickson 书第 7 章的主线，也是所有变换器建模的通用方法。后面每一节的内容，都能在这四步里找到位置。

1
分段线性：让非线性电路"暂时"变线性
开关在一个周期内分成若干区间。每个区间里，导通的器件等效为短路、截止的器件等效为开路，电路退化成纯线性网络。此时网络定理、KVL / KCL、叠加定理全部可用。关键认知：线性化是"分区间"换来的，代价是每个区间只有一套方程。
2
加权平均：把开关这个"罪魁祸首"消掉
按各区间时长（即占空比 d）对状态方程做加权平均。开关元件消失了，取而代之的是占空比这个连续变量。这一步成立的前提是开关频率远高于 LC 谐振频率——工程上通常要求 10 倍以上。
3
小信号线性化：在静态工作点附近"拉直"
平均模型里仍然有 d·x 这样的乘积项，仍是非线性的。在静态工作点上加小扰动（d = D + d̂，x = X + x̂），泰勒展开后丢掉二阶项，乘积项就变成了线性项。这一步的合法性来自"小信号"假设——扰动足够小，高阶项可以忽略。
4
拉普拉斯变换：把设计问题从方程里"读"出来
把微分方程变成代数方程，求传递函数、画 Bode、读极点零点。到这一步，"电路问题"才真正变成了"设计问题"——因为极点零点的位置直接告诉你：补偿器该用 Type II 还是 Type III、带宽能推到多高、会不会有 RHPZ 卡住上限。

01网络定理：把电路写成方程

网络定理本身是《电路》课的内容，难点不在定理，而在判断它在电力电子里什么时候能用、什么时候不能用。下面按"用在哪"来讲，每条都给出具体落点、公式和数字。

1.1 适用边界：一张表先说清

定理 / 方法在电力电子里能用在哪什么时候绝对不能用
戴维南 / 诺顿等效驱动回路、反馈分压、电流采样、滤波器等效受控源不会让定理失效——含受控源的网络一样有戴维南等效，只是求等效阻抗时必须用测试源法（外加源测 V/I），不能把受控源当独立源"关掉"
叠加定理小信号线性化之后的扰动分析、输出阻抗、音频隔离度原始开关电路——时变非线性，前提不成立
KVL / KCL永远可用，是分段线性分析的工具无（但必须逐区间用，不能跨区间）
最大功率传输谐振腔阻抗匹配、无线充电、感应加热恒功率负载场景（那里要的是反过来的条件）
二端口网络EMI 滤波器插入损耗、变压器高频模型ABCD / S 参数本来就是频率的函数，宽带场景照样适用；真正的限制是级联时端口阻抗不匹配——各级单独测都合格，连起来反而变差

一句话记住边界：受限制的不是定理本身，而是"把一个开关周期内的时变电路当作 LTI 系统"这个动作。它只在"开关被平均化、非线性被线性化"之后才成立。在原始开关电路上直接套传函、Bode 图或叠加定理，是这一层最常见的错误，且错得非常隐蔽——算出来的数往往"看起来合理"。

1.2 戴维南 / 诺顿等效

落点一：驱动回路

MOSFET 栅极在开关瞬态下可近似为一个电容 Ciss = Cgs + Cgd。驱动 IC 输出可等效为电压源 Vdrv 串内阻 Rdrv，再串外部栅极电阻 Rg，回路里还 unavoidable 地有驱动回路寄生电感 Lloop。

把它当作一阶 RC 处理，三个公式立刻可用：

τ = (Rdrv + Rg + Rg,int) · Ciss    开通时间常数
Ipk = Vdrv / (Rdrv + Rg + Rg,int)    驱动峰值电流，决定驱动器选型
Pg = Qg · ΔVgs · fsw    栅极驱动损耗，算入驱动 IC 热设计

为什么戴维南等效不够用：米勒平台

开通瞬间，漏极电压从 Vin 跌到 0，这个 dv/dt 通过 Cgd 耦合到栅极，抽走（或灌入）电流，把 Vgs "钉"在一个平台上。此时栅极电流几乎全部流向米勒电容，而不是给 Cgs 充电，所以 Vgs 停滞不动。

平台期持续时长 ≈ Qgd · (Rg + Rdrv) / (Vdrv − Vplat)    米勒平台时长

工程含义：开关损耗 ≈ VDS · ID · tcross · fsw，而交叉时间基本由米勒平台决定。所以降开关损耗有两条路：减小 Qgd（换器件，SiC / GaN 的核心优势），或加大驱动电流缩短平台（减小 Rg，但会加剧栅极振荡）。这两条路的权衡，就是驱动设计的全部内容。

落点二：负电阻效应与 Middlebrook 判据

这是网络定理在电力电子里最有工程价值、也最容易被忽略的一条。一个闭环稳压的变换器，从输入端看进去，低频段增量输入阻抗是负的。原因是恒功率特性：输入功率 Pin 恒定时，Vin 升高则 Iin 下降，于是

Zin,conv ≈ −Vin² / Pin    恒功率负载的增量输入阻抗（低频近似）

为什么写"≈"而且要限定"低频"：这个负电阻表达式只在环路还能维持近似恒功率的频段成立，大致是控制环带宽以内。频率升到接近或超过环带宽之后，变换器来不及维持恒功率，输入阻抗本身就变成明显的频率函数，不再是水平负电阻线（会出现幅值峰谷和相位变化）。所以它是低频近似，不是全频段等式。

如果变换器前面挂了一个 LC 输入滤波器，滤波器的输出阻抗 Zout,filt 会在 LC 谐振频率附近出现阻抗峰值。当这个峰值与负电阻的量级相当时，二者会发生显著的动态交互，可能降低稳定裕度甚至导致失稳——表现为输入电压振荡、甚至整机啸叫。

|Zout,filt(jω)| ≪ |Zin,conv(jω)|    Middlebrook 设计规则：工程裕量取 6 dB 以上

文献里把它称为"simple, although conservative"（简单但保守）的充分设计准则：只要满足，滤波器就不会显著扰动变换器原本的动态，价值在于不用精细建模就能先做出一版安全的滤波器。反过来，不满足也不等于一定振荡，只说明需要更精细的分析（minor-loop gain、Nyquist）或实测验证。

为什么"加个大电容就好了"经常不成立：加大滤波电容会同时改变谐振频率和峰值高度。电容加大后谐振频率下移，但如果在更低的频率上与其它阻抗（如线缆电感、源阻抗）形成新的谐振，峰值可能反而更靠近负电阻量级。正确做法是加阻尼——并联 RC 阻尼支路、或串联阻尼电阻，把谐振峰的 Q 压下来。

落点三：反馈分压网络

输出电压采样分压网络用戴维南等效为：

Rth = R1 ∥ R2      Vth = Vout · R2 / (R1 + R2)      H = Vref / Vout

Rth 会直接进入补偿器传函（影响 Type III 的直流增益和零点位置），同时它和误差放大器的输入偏置电流一起决定采样精度。所以分压电阻不能随便选大——选大了省电，但采样误差、噪声敏感度、环路参数漂移全都跟着变差。

ΔVout,offset = Ibias · Rth / H    偏置电流引起的输出误差

经验值：分压网络电流取 100 μA ~ 1 mA，既让偏置电流误差可忽略，又不至于显著降低轻载效率。

1.3 叠加定理：只能在线性化之后用

线性化之后，变换器有两个独立扰动源：输入电压扰动 v̂in 和负载电流扰动 îload。分别置零求解，再叠加，就得到两个关键指标：

音频隔离度  A(s) = v̂out(s) / v̂in(s)  |îload=0       输出阻抗  Zout(s) = −v̂out(s) / îload(s)  |v̂in=0

两个指标的物理意义：

  • 音频隔离度决定输入电压波动有多少"漏"到输出。前级是 PFC 时，输入上有 100/120 Hz 纹波，这个指标直接决定输出上的工频纹波大小。
  • 输出阻抗决定负载阶跃时的电压跌落深度，也是多模块并联均流设计的基础。

最常见的错误：在原始开关电路上直接套叠加定理。开关器件是时变非线性元件，叠加定理的前提（线性）根本不成立。必须先做状态空间平均、再线性化，才有资格谈叠加。跳过这一步得到的所有结论都是错的——而且因为数字往往"看起来合理"，错误很难被发现。

1.4 KVL / KCL → 状态空间平均法（完整推导）

这是网络定理在电力电子里最核心的落点。整个状态空间平均法（SSA）的第一步，就是"对每个开关子区间写 KVL / KCL"。下面用 Buck 完整走一遍，每一步都给出中间结果。

第一步：分段线性

开关周期 T 分成两个区间。每个区间里，导通的器件等效为短路、截止的器件等效为开路。

区间 1（0 < t < DT，开关导通、二极管截止）：

L diL/dt = Vin − vC      C dvC/dt = iL − vC/R

区间 2（DT < t < T，开关截止、二极管导通）：

L diL/dt = −vC      C dvC/dt = iL − vC/R

第二步：加权平均

区间 1 占 d，区间 2 占 (1−d)，加权平均：

L diL/dt = d(Vin − vC) + (1−d)(−vC) = d·Vin − vC
C dvC/dt = iL − vC/R

平均化成立的经验检查条件：开关频率远高于 LC 谐振频率（工程上取 10 倍以上，第 6 章算例里是 41 倍），此时状态变量在单个开关周期内变化很小，可以用周期平均值替代瞬时值。它是"检查条件"而不是充要条件——模型是否有效还取决于扰动频率范围（要显著低于 fsw）、状态变量的纹波大小，以及变换器是否真的工作在 CCM。如果 fsw 只有 f0 的两三倍，平均模型失效，必须用采样数据模型或直接时域仿真。

第三步：状态空间形式

取状态变量 x = [iL, vC]T：

dx/dt = Ax + Bd       A = [ 0, −1/L ; 1/C, −1/(RC) ]       B = [ Vin/L ; 0 ]

注意 B 里出现了 Vin/L——这个"开关网络"把输入电压和占空比耦合在了一起。这是电力电子建模的核心特征：控制量 d 通过输入电压作用于电感电流。

第四步：稳态工作点

令 dx/dt = 0，得到稳态解：

VC = D·Vin      IL = VC/R = D·Vin/R

第一个式子就是 Buck 的电压传输比，它从这里"自然长出来"，而不是靠伏秒平衡硬记。

第五步：加扰动、线性化

令 d = D + d̂，x = X + x̂，代入平均方程：

d(X+x̂)/dt = A(X+x̂) + B(D+d̂)

展开后分离静态项（等于 0）和扰动项。这里有个关键点：B 里的 Vin 是常数，所以 B(D+d̂) 是线性的，没有乘积项需要丢弃——Buck 的小信号模型是精确线性的（前提是输入电压恒定）。对 Boost / Buck-Boost，占空比会同时乘上状态变量，才需要丢掉二阶项。

dx̂/dt = Ax̂ + Bd d̂      Bd = [ Vin/L ; 0 ]

到这一步，网络定理的使命就完成了：非线性时变电路已经被翻译成一个线性时不变系统。剩下的事交给拉普拉斯。

1.5 对偶、等效变换与二端口网络

  • 变压器的 T 型等效：把实际变压器拆成励磁电感 Lm、漏感 Llk、理想匝比 n。反激的励磁电感决定储能，正激的复位靠它，LLC 的谐振腔由它和漏感共同构成。折算到原边或副边是必须练熟的基本功——折算是把 L 乘 n² 还是除 n²，判断方法是保持能量和磁通不变。
  • Y-Δ 变换：三相系统、多相 Buck 的等效简化。多相 Buck 里 N 相并联在输出纹波与低频动态的意义上可以等效为一个开关频率 fsw×N 的单相，这个结论来自等效变换。注意"等效"的边界：N 个电感仍是彼此独立的储能元件，各相的电流环、均流、轻载切相都是单相等效模型看不到的，不能说整个动态系统都等价于一个 N 倍频单相 Buck。
  • 二端口网络：EMI 滤波器的插入损耗 IL = 20 log(V1/V2) 用 ABCD 参数算。共模 / 差模等效电路、变压器的高频模型（寄生电容构成共模噪声通路）都靠这套语言描述。EMI 滤波器的难点不在单级，而在级联后的阻抗不匹配——每一级单独测都合格，连起来反而变差，这是二端口级联的经典问题。

02拉普拉斯变换：从微分方程到设计洞察

2.1 为什么是它

电感和电容的本征关系是微分方程：v = L di/dt，i = C dv/dt。拉普拉斯变换把 d/dt 映射成乘 s，于是整个电路变成一个纯代数网络：

ZL = sL      ZC = 1/(sC)

之后用分压、分流公式就能解——和你大二学的电阻网络一模一样。

不做拉普拉斯会怎样：你仍然可以解微分方程（数值解或解析解），也能得到波形。但你得不到"极点零点"这种结构化的洞察——而设计决策恰恰来自极点零点，而不是波形。看到 ω0 就知道必须补 180°、看到 RHPZ 就知道带宽有硬上限，这些都是时域波形给不了的信息。这是拉普拉斯在电力电子里不可替代的原因。

三个参数的深入解读

  • ω0 = 1/√(LC) —— 双重极点。LC 谐振频率。相位行为是：远低于 ω0 时相位接近 0°，穿过双极点区域后快速下降，足够高频时渐近 −180°。不是"低于 ω0 就已经滞后 180°"——这是很常见的误读，会让人以为只要工作在低频就没事。穿越频率落在 ω0 之上时，相位随 fc/ω0 增大而趋近 −180°：fc 取 2、3、5、10 倍 ω0 时分别约 −127°、−143°、−157°、−169°（均未计入 ESR 零点）。一旦落在 −150° 以下，补偿器就需要两个零点把相位抬回来，这是电压模式 Buck 常用 Type III 的原因。
  • ωz = 1/(rCC) —— ESR 零点。相位 +90°，看起来是"免费"的相位裕度。但 rC 随温度和频率剧烈变化——铝电解电容在 −40 ℃ 下 ESR 可能是常温的数倍，零点位置跟着跑；而陶瓷电容的 ESR 极小，零点在几百 kHz 以上，基本没用。绝对不要把环路裕度押在 ESR 零点上。
  • Q —— 品质因数。决定谐振峰的尖锐程度。Q 高则谐振峰高、增益裕度吃紧、阶跃响应振铃明显。注意 Q ∝ 1/(L/R)，所以轻载（R 大）时 Q 升高——轻载往往是环路最恶劣的工况，这一点和很多人的直觉相反。

2.5 右半平面零点：Boost 与反激的带宽天花板

Boost、Buck-Boost、反激在 CCM 下都存在右半平面零点（RHPZ）。这里最容易记混：不同拓扑的 RHPZ 公式不一样——Boost 的分子里没有 D，带 D 的是 Buck-Boost 一族：

ωrhpz = R(1−D)² / L    Boost CCM（无 D）
ωrhpz = R(1−D)² / (D·L)    Buck-Boost 一族（含 CCM 反激，注意折算侧）

记混的代价很大：同样的 R、L、D，两个公式差 1/D 倍。本节的算例 D = 0.75，两者相差 3 倍——按错的那个算，你会以为带宽上限有 3.06 kHz，实际只有 2.29 kHz。

RHPZ 的恶劣之处在于它的相位和增益符号相反。对比一下 LHP 零点和 RHP 零点——它们的幅频特性完全相同，相频特性正好相反：

RHPZ 的物理含义是"先反后正"。以 Boost 为例，正确的作用链是：占空比突然增大 → 开关 ON 时间变长 → OFF 时间立刻变短 → 在电感电流还没来得及升上去之前，二极管向输出端送能量的时间反而先减少了 → 输出电容要多承担负载电流 → Vout 先下跌；要等几个周期后电感电流建立到新的稳态值，输出才回升。

关键在"能量传输时间先变短"，而不是"电感从电容抽电荷"——Boost 的电感只在 OFF 期间才与输出端连通，ON 期间它被输入源充电、与输出端是断开的。这个"先反"的行为在传递函数里就表现为一个右半平面零点。

工程结论：RHPZ 频率是环路带宽的硬上限。穿越频率必须远低于它，通常取 fc ≤ frhpz / 3 ~ / 5。这就是为什么 Boost 的带宽做不高，也是为什么反激在 CCM 下环路特别难调。

但"减电感提带宽"这个方向本身是对的：frhpz ∝ 1/L，减小 L 会把 RHPZ 推高，不是推低——这一点很容易写反。真正的代价在别处：减小 L 会抬高电感纹波、峰值电流、磁芯与铜损、器件电流应力，还可能把变换器推进 DCM。所以结论不是"电感越小越好"，而是在纹波、损耗、应力约束下取尽可能小的 L，换取 RHPZ 上移和带宽空间。

但轻载的问题不只是 Q：轻载还会让变换器离开 CCM（见 6.7 节），此时二阶 CCM 模型本身就失效了。所以"轻载更危险"的正确含义是"最轻载工况要单独建模、单独校验"，而不是"把满载模型外推到轻载"。

另外注意 rCC 在轻载时角色的变化：满载时 L/R = 6.67 μs 远大于 rCC = 1.1 μs，阻尼几乎全来自负载；轻载时 L/R = 0.67 μs 反而小于 rCC，ESR 成了主要阻尼源——所以 Q 只升到 12.5，而不是按 1/(L/R) 外推出来的 33。

直流增益 Gvd(0) = Vin，这是开环增益的一部分；开环增益决定负载调整率。补偿器里的积分环节（s 在分母）让直流增益趋于无穷，从而获得零稳态误差。这是"为什么补偿器一定要有积分项"的数学依据。

终值定理的两个前提别漏：① sF(s) 的极点必须都在左半平面（除原点极点外，不能在右半平面或虚轴上），即系统稳定；② 终值确实存在且有限。所以严谨的说法是"在闭环稳定、且没有饱和限幅等非线性的前提下，积分项带来零稳态误差"，而不是"只要有积分就零误差"——一个已经在振荡或反复限幅的环路，谈不上稳态。

那个"8 dB"要加限定：只有在远高于两个 f2（即远高于 79.6 MHz）的渐近段，两条包络的差值才是恒定的——f2 以上包络幅度 ∝ f2，比值 2.5 倍即 20 log 2.5 = 8 dB。在 31.8 ~ 79.6 MHz 的过渡段，两条包络斜率不同，差值从 0 dB 连续变到 8 dB，并不是固定 8 dB。理解这一点，就不会把 EMI 当成"后期整改的杂事"，而会在选器件和定驱动电阻时就把这笔账算进去。

3.1 误差放大器就是补偿器

运放加阻抗网络，传递函数只有一条公式：

Gc(s) = −Zf(s) / Zin(s)

所有补偿器类型，都是这条公式在不同阻抗网络下的特例。区别只在于 Zf 和 Zin 里放了几组 RC。

3.2 Type I / II / III 的极点零点配置

为什么 Type II 到不了 +90°：零点带来 +90°，但那个高频极点同时带来 −90°，两者在频率上不可能完全分开。一对零极点的最大提升量有闭式解——取几何中心 ω = √(ωzωp)，记间隔比 k = ωp/ωz：

φmax = 2·arctan(√k) − 90° = arcsin( (k−1)/(k+1) )

代几个常用间隔：k = 9（±1 倍频程）→ 53°；k = 25（零点 1/5、极点 5 倍）→ 67°；k = 49 → 74°；只有 k → ∞ 才趋近 90°。所以"+70°"对应的正是"零点放 1/5、极点放 5 倍"这种常用间隔（k = 25），它是实用设计值，不是数学上限——间隔拉更宽能再多一点，代价是零极点离穿越频率太远、中频段增益抬不起来。Type III 是两对，理论上限 180°；每对按 k = 25 能拿到约 135°，要凑到 160° 得把间隔拉到 k ≈ 100（零点 1/10、极点 10 倍）。

关键澄清：+70° 是"相对积分器"的提升量，不是补偿器在 fc 处的绝对相位。因为所有补偿器都含一个积分极点，绝对相位永远从 −90° 起步。选择补偿器时要比对的是绝对相位：

Type II−90° ~ −20°穿越处相位 ≥ −160° 的对象

但别把"电压模式 Buck 必须用 Type III"当成定理。准确的说法是：当穿越频率落在 LC 双极点之上、且 ESR 零点来不及提供足够相位时，通常需要 Type III。以下情况 Type II 完全可能可行：crossover 取得足够低（在 f0 附近或更低）；ESR 零点恰好落在 LC 双极点附近，本身就补掉一部分相位；或者被控对象已有其他有利的零极点。选型依据永远是"在选定 fc 处被控对象相位是多少、缺口有多大"，而不是拓扑名字。

3.3 补偿器设计流程

拿到 Gvd(s) 之后，按下面七步走。第 6 章会用完整算例演示一遍。

1
确定环路组成
T(s) = Gc(s) · Gvd(s) · Fm · H。先算清 Fm（调制器增益）和 H（分压比），很多人漏掉 Fm，导致设计值与实测差一个数量级。
2
选穿越频率 fc
经验值 fc = fsw/10 ~ /5（数字控制取下限）。再检查三个硬约束：低于 RHPZ 的 1/3、低于 ESR 零点、低于开关频率的 1/2。
3
算出该点的相位缺口
代入 Gvd(jωc) 求相位，目标相位裕度取 45°~60°，反推补偿器需要提供的相位。
4
按缺口选补偿器类型
缺口 ≤ 70° 选 Type II，≤ 160° 选 Type III。超过 160° 说明带宽选得太高，回到第 2 步降低 fc。
5
放置零点与极点
零点通常放在 f0 附近（抵消 LC 双重极点），高频极点放在 fz,esr 附近（抵消 ESR 零点），第二个高频极点放在 fsw/2 附近（抑制开关噪声）。
6
配平增益
令 |T(jωc)| = 1，反算出积分器的单位增益频率 ωp0。这一步决定直流增益，也就是负载调整率。
7
反算元件值并校验
把极点零点位置映射到 RC 取值（注意选 E96 标称值），然后重新代入完整传函校验——元件取整后极点零点会移动，必须复算相位裕度。最后在最轻载和最重载两种工况下各校验一次。

3.4 TL431 + 光耦：隔离反馈的行业标准

隔离电源的经典环路：输出分压 → TL431（可调基准兼误差放大器）→ 光耦 → 原边 PWM 控制器。

三个必须知道的坑

  • TL431 自身的增益带宽是天花板，通常只有几十 kHz。环路带宽想超过它，得换方案（如光耦 + 独立运放，或数字隔离器 + 原边控制）。
  • 光耦引入一个低频极点（常在几 kHz 量级），是相位裕度的主要杀手。补偿网络通常放在 TL431 的 REF 到阴极之间，用它的零点去抵消这个极点。
  • 光耦的 CTR 随温度和老化衰减，直接导致环路增益漂移。设计时要在 CTR 最差工况（高温 + 寿命末期，可能只有标称值的 50%）下校验相位裕度。
T(s) ∝ CTR   →   CTR 减半，开环增益降 6 dB，穿越频率下移

工程做法：把 CTR 最差工况下的穿越频率作为设计点，而不是标称值。否则常温调试合格的产品，在高温老化后可能出现响应变慢甚至不稳定。

3.5 比较器、PWM 调制与斜率补偿

PWM 的物理本质是误差放大器输出 Vc 与固定斜率斜坡 Vramp 比较：

d = Vc / Vramp   →   Fm = 1/Vramp    调制器增益，电压模式

这个 Fm 就是环路增益 T(s) = Gc·Gvd·Fm·H 里的一项。很多人算环路时漏掉它，结果实测和设计差一个数量级。峰值电流模式的 Fm 形式不同，需要考虑斜率补偿量：

Fm = 1 / (ma + mc)    峰值电流模式，ma 为补偿斜坡斜率，mc 为电感电流下降斜率

斜率补偿：模电知识直接决定稳定性

峰值电流模式在 D > 0.5 时会发生次谐波振荡（subharmonic oscillation）：开关波形一大一小交替出现，电感电流包络呈"成对"振荡。原因是扰动在电流环里被逐周期放大。必须加入斜坡补偿，补偿量通常取：

ma ≥ 0.5 · mc    最常用的经验值；要求更高稳定性时取 ma ≥ mc

这不是可选项。很多"电流模式不需要补偿"的说法只适用于 D < 0.5 的场合（如 Buck 从 12 V 降到 5 V）。一旦占空比超过 50%（Boost、PFC、反激），不加斜率补偿必然振荡。判断方法很简单：看占空比，不看拓扑名字。

3.7 器件小信号模型与米勒效应

  • MOSFET 在驱动回路里表现为 Ciss、Coss、Crss 三个电容和跨导 gm。其中 Crss = Cgd，就是米勒支路。
  • 米勒平台：开通时 Cgd 把漏极电压变化反馈到栅极，Vgs 被"钉住"形成平台。真正的开关损耗几乎全在平台期产生——想降损耗，要么提高驱动电流缩短平台，要么选 Qgd 更小的器件（这正是 SiC / GaN 的核心优势）。
  • 栅极振荡：驱动回路寄生电感 Lloop 与 Ciss 构成高频谐振，可能让 Vgs 超过绝对最大值，直接损坏器件。对策是加大 Rg 阻尼或在栅极串铁氧体磁珠。SiC / GaN 开关更快、Ciss 更小，这个问题更严重。
  • 共源极寄生振荡：Cgd 引入的反馈路径可能让器件在开关过程中产生 MHz 级自激振荡，表现为波形上的"毛刺"。诊断方法是改变 Rg 看振荡是否消失。

4.2 采样延时：数字环路最大的坑

数字控制一个周期内的动作是：ADC 采样 → ISR 计算 → 在下一个周期起点更新 PWM。考虑零阶保持（ZOH）的等效延时，总有效延时约为：

Td ≈ 1.5 Ts    1 Ts 计算与等待 + 0.5 Ts ZOH 等效
模型
单采样单更新：每周期起点采样 → 本周期内算完 → 下一周期起点更新 PWM
假设
ISR 能在一个开关周期内跑完；PWM 影子寄存器在周期起点加载；无多采样、无特殊触发时序
有效范围

近似

⚠️ 1.5Ts 是"这套时序"的结果，不是数字控制的固有规律。实际控制延时取决于 PWM 架构、ADC 触发时刻、ISR 完成时刻和寄存器加载时刻，不同 MCU 差别很大——周期中点采样、当前周期算完就更新、影子寄存器在不同事件加载、高频 ADC 多采样、CLA / 硬件加速、把 ADC SOC 精确排到 PWM reload 之前，都会改变 Td。所以先查清你所用的具体时序，再决定 Td 取多少——这一步查错，后面所有裕度计算都跟着偏。

它在穿越频率处造成的相位滞后是：

φ = −ωTd = −2π fc · 1.5 Ts = −3π fc / fs

换成角度制，得到一个非常好用的设计速算公式：

φdeg = −540 · (fc / fs)    延时造成的相位损失（度）

代入第 6 章算例的参数（fc = 30 kHz，fs = 300 kHz，Ts = 3.33 μs，Td = 5 μs）：

φ = −2π × 30000 × 5 μs = −0.942 rad ≈ −54°

这一项白丢 54° 相位裕度。而设计目标相位裕度通常也就 45°~60°。所以数字环路的补偿器必须比模拟环路更激进（用更多零点换相位），或者把带宽压下来。很多"数字电源实测比仿真差很多"的案例，根源就在这里。

4.3 Z 域与离散化

把设计好的 Gc(s) 搬到 DSP 上，需要离散化。最常用的是双线性变换（Tustin）：

s = (2/T) · (z−1)/(z+1)

它把 s 左半平面正确映射到 z 单位圆内（稳定性不变），且没有频率混叠。代价是频率轴被非线性压缩（frequency warping），高频段的极点零点位置失真。

对策是预畸变（prewarping）——在穿越频率处让数字频率响应与模拟一致：

s = (ω0 / tan(ω0T/2)) · (z−1)/(z+1)    ω0 通常取穿越频率

离散化后转成差分方程，就是可以直接写进 C 代码的形式：

y[n] = b0x[n] + b1x[n−1] + b2x[n−2] − a1y[n−1] − a2y[n−2]

系数量化陷阱：在定点 DSP 上，系数位宽不足会让实际的极点零点偏离设计值。高 Q 的极点对系数量化尤其敏感，可能直接跑出单位圆导致发散。对策是把高阶传函分解成多个二阶节（biquad）级联——注意，拆成 biquad 并不会改变极点本身的位置，极点还是那些极点。它的作用是：① 把高阶直接型（系数对极点位置极度敏感）换成若干低阶节，降低系数量化对极点零点位置的敏感度；② 便于逐节定标，控制每一级内部的动态范围、避免中间结果溢出。此外用 Q15 / Q31 时把系数归一化到接近 1 的范围，也能改善精度。

4.4 DPWM 分辨率与极限环

数字 PWM 的占空比分辨率由计数时钟和开关频率决定：

ΔD = fsw / fclk   →   ΔVout = Vin · ΔD

用第 6 章算例：fsw = 300 kHz，DPWM 时钟 200 MHz，则 ΔD = 0.15%，对 12 V 输入意味着 18 mV 的最小调节台阶。

如果这个台阶比 ADC 的 LSB 还大，就构成了极限环振荡（limit cycle）的典型高风险条件：输出电压在相邻两个码之间来回跳，无法稳定在目标值上，表现为输出纹波呈规律性"台阶状"跳动、频率远低于开关频率。

但它不是"必然发生"的充要条件。是否真的形成稳定的极限环，还取决于环路增益、积分器结构、ADC 定标、输出噪声、有没有加 dither，以及限幅/死区等非线性。分辨率不匹配是最常见的诱因，不是唯一判据。

现象诊断对策
输出在几个固定电平间跳ΔVout（DPWM 台阶）> ADC LSB优先提高 DPWM / HRPWM 分辨率；或重新缩放控制量、加 dither
低频振荡（几 kHz）环路带宽过高，或量化噪声被放大降低 fc，或在补偿器里加低通
稳态误差周期性变化积分器在量化边界上反复加死区或抖动（dither）

空有 16 位 ADC 配 8 位 DPWM，性能由差的那个决定。做数字电源选型时，先算 DPWM 台阶折合到输出的电压，再和 ADC 的 LSB 比——两者量级相当才是合理配置。注意修正方向：应该去提高 DPWM 分辨率（延迟线结构 delay-line DPWM、混合 DPWM 粗调 + 细调、HRPWM），而不是反过来降低 ADC 分辨率去"凑匹配"——后者只是把量化误差换个地方，还白丢 ADC 的动态范围。

4.5 逻辑与时序约束

  • 死区时间：避免桥臂直通。可用硬件（RC 延时 + 门电路）或软件（PWM 模块的死区寄存器）。死区越长越安全，但会加大体二极管导通损耗和波形畸变——SiC 的体二极管压降大，死区代价尤其明显。
  • 保护走硬件还是软件：硬件比较器响应几十纳秒，软件保护要等一个开关周期。SiC 的短路耐受时间只有几微秒，决定了必须走硬件。这是"数电时序"概念在功率级的硬约束。
  • 中断优先级：PWM 中断 > ADC 中断 > 通信中断。优先级排错会导致占空比抖动，表现为输出纹波上叠加随机噪声。
  • 时序预算：ADC 转换时间 + ISR 执行时间 < 一个开关周期。开关频率一提高，这个预算最先崩——这也是为什么高频数字电源必须用带专用协处理器的控制器（如 TI C2000 的 CLA）。
  • 时钟抖动：PWM 时钟抖动直接转化为占空比抖动，进而变成输出纹波和相位噪声。对给 ADC 供电、射频供电这类高精度电源，这是硬指标，需要在选型阶段就确认时钟源的抖动指标（通常要求 < 100 ps）。

5.1 环路增益的定义

前面所有工作的落点都是这一个量——开环环路增益：

T(s) = Gc(s) · Gvd(s) · Fm · H
项含义来自哪一章
Gc(s)补偿器第 3 章（模拟）或第 4 章（数字，用 Gc(z)）
Gvd(s)功率级控制到输出第 2 章
Fm调制器增益 = 1/Vramp第 3.5 节，最常被漏掉的一项
H反馈分压比 = Vref/Vout第 1.2 节

把环路在某个点断开，注入小信号，测量"绕一圈回来"的增益——这就是 T(s)。稳定判据：T(s) 的幅频在穿越 0 dB 时，相频必须离 −180° 还有足够距离。

5.4 实测方法

环路增益不能"直接量"，只能通过注入小信号、测两点电压比来间接得到。这是电力电子测试里最需要技巧的一项。

1
选注入点
在反馈环路里找一个阻抗"两边都合适"的位置串入小电阻（通常 10 ~ 50 Ω）。阻抗太低则注入不进去，太高则引入额外极点。经典做法是在输出分压的上端电阻处注入。
2
隔离注入
用隔离变压器（注入变压器）把扫频信号耦合进去，避免分析仪的接地点和功率地形成回路。这是最常见的翻车点——不隔离会直接引入共模噪声，测出来的曲线完全不可信。
3
控制注入幅度
注入信号必须足够小，让环路工作在线性区。判断方法：把注入幅度减半，如果测出的曲线不变，说明仍在线性区；如果曲线变了，说明幅度过大，测到的是大信号特性。
4
测量并验证
测注入点两侧的电压比，得到 T(s)。同时用示波器看输出电压，确认没有明显畸变。建议在满载、半载、轻载三种工况下各测一次——轻载往往是最恶劣工况（Q 最高）。

常用仪器：Bode-100 环路分析仪、Keysight E5061B、Venable 系列。数字电源也可以注入到参考电压或直接给占空比加扰动，省掉注入变压器的麻烦。

5.5 预测与实测偏差的来源

仿真和实测对不上是常态。下表按"出现频率"排序，帮助快速定位：

  • 强制 CCM（forced-CCM）：同步整流低边管保持互补导通、允许电感电流反向，变换器仍工作在 CCM，上面的 Q = 12.5 分析继续有效。这是多数同步 Buck 的默认配置。
  • 二极管仿真 / PFM / 打嗝模式（diode emulation、pulse skipping）：控制器在轻载主动进入 DCM 或降频，此时被控对象变成另一个模型——阶次降低、出现新的极点零点、环路增益随负载变化，必须换模型重新分析，不能在 CCM 的 Bode 图上继续讨论。

这是数字电源和低功耗设计里最常被忽略的一条：同一个环路，满载和轻载可能根本不是一个系统。

08十个常见误区

  1. 在开关电路上直接套叠加定理。非线性时变，不成立。必须先平均化、再线性化。
  2. 漏掉调制器增益 Fm。环路增益算出来和实测差一个数量级，多半是这里。电压模式 Fm = 1/Vramp，峰值电流模式还要考虑斜率补偿。
  3. 把环路裕度押在 ESR 零点上。ESR 随温度、频率、老化剧烈变化，低温下可能翻数倍，零点位置跟着跑。
  4. 无视 RHPZ 硬拉带宽。Boost / 反激 / Buck-Boost 在 CCM 下带宽上限由 RHPZ 决定，强行提高必然振荡。注意方向别写反：frhpz ∝ 1/L，减小电感是把 RHPZ 推高、给带宽腾空间（代价是纹波、峰值电流和器件应力上升）。另外别把 Boost 和 Buck-Boost 的 RHPZ 公式混用——Boost 分子里没有 D。
  5. 数字控制忽略采样延时。白丢 50° 以上相位裕度，实测必然和设计对不上。用 φ = −540·fc/fs 先估一遍。
  6. 把模拟补偿器直接离散化就上机。正确做法是把延时当作被控对象的一部分，重新设计补偿器。
  7. 离散化不做预畸变。穿越频率处的相位和设计值有系统性偏差。
  8. 定点 DSP 上不检查系数量化。高 Q 极点实现失真，甚至跑出单位圆。高阶传函要拆成 biquad 级联。
  9. 只在满载校验环路。轻载 Q 升高、谐振峰抬高，往往是最恶劣工况；而且轻载还可能离开 CCM（本例 18% 满载以下就进 DCM），此时连模型都要换——正确做法是"最轻载工况单独建模、单独校验"，而不是把满载模型外推过去。
  10. 只看幅频不看相频。稳定性判据是相位裕度，幅频交叉点只是个坐标。看到 −40 dB/dec 穿越 0 dB 就该高度警觉——但这是经验预警，最终还要看实际相位曲线。

10自测：检查你是否真的掌握了

答案折叠在题目下方。先自己想，再展开对照。

1 · 为什么不能在原始开关电路上直接用叠加定理？

开关器件是时变非线性元件，叠加定理的前提（线性）不成立。必须先做状态空间平均把开关"消掉"，再线性化，得到线性时不变的小信号模型之后，叠加定理才有资格使用。跳过平均化直接叠加，得到的结论在数学上无意义。

2 · Buck 的 LC 双重极点为什么要求 Type III 补偿器？

双重极点在 ω0 以上渐近贡献 −180° 相位，但"渐近"是关键——fc 取 3、5、10 倍 ω0 时被控对象相位分别约 −143°、−157°、−169°。若穿越频率取在 ω0 之上较远处（相位已接近 −180°），要获得 60° 相位裕度就需要补偿器在穿越频率处提供接近 +60° 的绝对相位。而 Type II 的绝对相位上限只有 −20°（积分器的 −90° 加上最多 +70° 的提升），做不到；Type III 的上限是 +70°，可以。注意区分"相对积分器的提升量"和"绝对相位"。

补一句：这不是"电压模式 Buck 必须 Type III"的定理，只是"在这个 crossover 选择下必须 Type III"。把 fc 降到 ω0 附近或更低，相位缺口就小得多，Type II 也可能够用。

3 · 一个 Boost 的 RHPZ 在 3 kHz，你能把穿越频率定到 8 kHz 吗？

不能。RHPZ 的幅频是 +20 dB/dec（增益上升）、相频是 −90°（相位滞后），两者符号相反，无法用常规补偿器抵消。工程上要求 fc ≤ frhpz/3 ~ /5，即 ≤ 0.6 ~ 1 kHz。定到 8 kHz 必然振荡。

4 · 数字控制 fc = 20 kHz、fs = 200 kHz，采样延时损失多少相位裕度？

φ = −540 × (20/200) = −54°。这个量级几乎等于整个设计目标相位裕度，所以必须把延时算进设计，而不是事后补偿。

5 · 为什么"加个大滤波电容"解决不了输入滤波器振荡？

因为问题是负电阻与滤波器输出阻抗峰值的动态交互，不是滤波能力不足。加大电容会移动谐振频率和峰值高度，可能让峰值更靠近负电阻量级。正确做法是给滤波器加阻尼（RC 阻尼支路或并联阻尼电阻），按 Middlebrook 设计规则把谐振峰压到 |Zin| 以下约 6 dB 的工程裕量。注意它是保守的充分设计规则——满足它就保证滤波器不显著扰动变换器原本的动态；但不满足不等于"必振"，越线后是否真的失稳还要看 minor-loop / Nyquist 分析或实测。

6 · 补偿器的直流增益为什么必须无穷大？

由终值定理，稳态误差反比于开环直流增益 T(0)。只有补偿器含积分环节（原点极点），T(0) 才趋于无穷，才能得到零稳态误差。这也是为什么 Type I / II / III 都含一个积分极点。

7 · 轻载还是满载的相位裕度更差？

通常轻载更差。Q = 1/(ω0(L/R + rCC))，负载变轻则 R 增大、L/R 减小、Q 增大，LC 谐振峰抬高，fc 附近的相位下降更多。所以必须在最轻载工况下复算。

8 · Bode 图上环路以 −40 dB/dec 穿越 0 dB，说明什么？

这是一个强烈的预警信号：通常说明有两个极点没被补偿，相位裕度会非常差。−20 dB/dec 穿越对应 PM 理论上限约 90°，−40 dB/dec 对应约 0°。看到这种斜率就该先回去查补偿器。

但严格说，局部幅频斜率不能唯一决定相位——系统可能还有零点、远端极点或非最小相位环节。所以它是经验判据，最终仍要看实际的环路相位曲线（或 Nyquist / 实测）。

9 · DPWM 时钟 200 MHz、开关频率 300 kHz、输入 12 V，输出最小可调台阶是多少？为什么它重要？

ΔD = 300 kHz / 200 MHz = 0.15%，ΔVout = 12 V × 0.15% = 18 mV。如果这个台阶大于 ADC 的 LSB，就构成了极限环振荡的典型高风险条件——输出在相邻两个码之间来回跳，无法稳定。所以 ADC 和 DPWM 的分辨率要匹配，性能由差的那个决定。对策是提高 DPWM 分辨率（HRPWM / 延迟线 / 混合结构）或重新缩放控制量，而不是去降低 ADC 分辨率"凑匹配"。

10 · 实测环路和仿真对不上，你会按什么顺序排查？

先查测量本身：注入是否隔离、注入幅度是否过大、注入点阻抗是否合适（这三项最容易出错）。再查模型参数：数字环路的实际延时（用示波器直接量）、电容 ESR 的实际值、光耦 CTR 的实际工作点。最后查寄生和非线性：高频段（> fsw/2）本身不可信；不同负载下曲线形状变化说明存在非线性。按"测量 → 参数 → 模型"的顺序排查效率最高。
