这个模块在电力电子里到底干什么。功率级本身只是"会开合的开关 + 电感电容"。真正决定电源好不好用的，是外面那一圈反馈：输出电压能不能顶住负载跳变、启动会不会过冲、并联会不会振荡、参数漂了还稳不稳。控制理论就是回答这些问题的语言——它把"我觉得应该稳"变成"相位裕度 52°、灵敏度峰 1.35、穿越频率 8 kHz"这种可以写进规格书、可以复测的数字。

电力电子工程师不需要"学完控制理论"。你需要的只是下面五个问题各自的答案，以及对应的那套工具。其余部分（例如 Nyquist 判据的严格证明、Lyapunov 稳定性、最优控制）知道它在哪本书里就够了。

控制理论的两条"红线"

这份文档反复强调两件事，因为它们是最常被搞错、代价也最大的两条：

红线一：小信号线性化只在工作点附近成立。所有传递函数、Bode 图、PM 计算，都是"在某个稳态工作点（Vin、Vout、Iout、D 固定）做微扰"的结果。Vin 从 12 V 跳到 24 V、D 从 0.275 跳到 0.55，Q、f₀、RHP 零点全部平移，原来算的 60° 裕度可能只剩 20°。所以控制设计必须在多个工作点重复校验，而不是只算额定点。

红线二：相位裕度是"环路增益在穿越频率处的相位"，不是"补偿器的相位"。很多资料只画补偿器 Gc(s) 的 Bode 图就宣称"Type II 能提升 70° 相位"。那个 70° 是相对于积分器 −90° 的提升量，不是绝对相位。Type II 在 fc 处的绝对相位实用上限约 −20°（结构上可逼近 0°，但不能为正），Type III 约 +70°（理论上可逼近 +90°）。拿"提升量"去和被控对象的相位缺口比对，是电力电子控制设计里最高频的错误。

01系统语言：信号、LTI 与卷积

控制理论有自己的一套词汇。这一章只做一件事：把这套词汇和电力电子里的实物对上号。看不懂"LTI""因果""卷积"，后面所有公式都只是符号游戏。

1.1 先分类：你的系统到底属于哪一类

控制理论的所有结论都有前提。用错前提，结论就错。所以第一步永远是给系统归类。

性质严格定义电力电子里的实际含义破坏它会发生什么
线性满足叠加性只有"小信号微扰"满足大信号下传递函数无意义
时不变输入延迟 τ，输出只延迟 τ额定工况近似成立慢启动段用额定补偿器会过冲
因果输出不依赖未来输入永远成立（物理系统）——
稳定 (BIBO)有界输入必有界输出对最小有理实现等价于极点全在 LHP输出发散到限幅，保护动作
最小相位无 RHP 零点Buck 是；Boost / 反激不是带宽被 RHP 零点锁死

适用边界。"叠加定理不能在开关电路上用"——这句话只说对了一半。准确的说法是：叠加定理不能在未平均化的开关电路上直接用，因为开关动作本身是非线性的。但经过状态空间平均（或 PWM switch 模型）得到平均模型后，在稳态工作点做微扰，得到的小信号模型就是线性的，此时叠加定理完全成立。第 1.4 节给完整推导。

1.2 线性时不变系统的四种等价描述

LTI 系统可以用四种等价的方式描述，它们之间的换算是控制工程师的日常操作。这里的"等价"指输入—输出行为等价，默认有限维、因果、适当的 LTI 系统；一旦涉及内部状态，须采用最小实现——传递函数只描述零初值下的输入—输出关系，并不能唯一确定内部状态实现（非最小实现中可能存在被传函消去的不可控 / 不可观模态）。

1.3 卷积：为什么"系统记忆"能用一个函数概括

卷积是控制理论里最容易被跳过、又最不该跳过的一步。它的物理含义非常朴素：把输入切成无数个极窄的脉冲，每个脉冲按系统的脉冲响应留下痕迹，把所有痕迹叠加起来就是输出。

y(t) = (h * x)(t) = ∫−∞∞ h(τ)·x(t − τ) dτ 　　LTI 系统输出 = 脉冲响应与输入的卷积

卷积的工程价值在于它把"解微分方程"变成"看一个函数的形状"。你不需要每次都解 ODE，只要知道 h(t) 里有哪些振荡分量、各自衰减多快，就能预判任意输入的响应。而 h(t) 的每一个振荡分量，恰好对应 H(s) 的一个极点：

极点位置h(t) 里的分量时域观感频域观感
s = −σ（实极点）e−σt单调衰减，时间常数 1/σ−20 dB/dec 拐点
s = −σ ± jωde−σt·sin(ωd t + φ)衰减振荡，周期 2π/ωd−40 dB/dec 段 + 相位陡降
s = 0（原点）常数（不衰减）积分，输出持续累积−20 dB/dec 全程 + −90°
s = +σ（右半平面）e+σt指数发散系统不稳定；Bode 仍可绘制，但稳态频响解释与简单裕度判据需谨慎（须考虑 RHP 极点数）

1.4 KVL / KCL → 状态空间平均法（完整推导）

这是"控制理论落地到变换器"的关键一步。目标是：把一个开关电路（非线性、时变）变成一个 LTI 传递函数，并且明确知道哪些近似被用掉了。

1
选状态变量
电感的电流 iL、电容的电压 vC。n 个独立储能元件 → n 阶系统。
2
分段写状态方程
开关 ON 时 ẋ = A₁x + B₁u；OFF 时 ẋ = A₂x + B₂u。用 KVL / KCL 逐段写出。
3
按占空比加权平均
ẋ = [d·A₁ + (1−d)·A₂]·x + [d·B₁ + (1−d)·B₂]·u。这一步丢掉的是开关纹波（要求纹波 ≪ 平均值）。
4
求稳态工作点
令 ẋ = 0 解出 X = −A⁻¹BU，得到 D、IL、VC。这是后面所有线性化的展开点。
5
加微扰并线性化
令 d = D + d̂、x = X + x̂，代入后丢掉二阶项 d̂·x̂，得到 ẋ̂ = A·x̂ + B·d̂。此时才是 LTI。
6
拉普拉斯变换求传函
Gvd(s) = C(sI − A)⁻¹B + D。化成标准形式后，根据拓扑不同可得到 LC 双极点、ESR 零点，以及 Boost / Buck-Boost / 反激等拓扑特有的 RHP 零点（Buck CCM 本身没有 RHP 零点）。

以 Buck CCM 为例，完整走一遍：

ẋ = [d·A₁ + (1−d)·A₂]·x + [d·B₁ + (1−d)·B₂]·u 　状态空间平均方程
ẋ̂ = A·x̂ + [(A₁−A₂)X + (B₁−B₂)U]·d̂，　A = D·A₁ + (1−D)·A₂ 　微扰线性化（丢掉二阶项）
Gvd(s) = C(sI − A)⁻¹·[(A₁−A₂)X + (B₁−B₂)U] 　占空比 → 输出 的传递函数

这套推导的四个适用边界（比结论本身更值钱）：

① 纹波要小：iL 的纹波 ΔiL ≪ IL，否则"平均"没有意义。本例 ΔiL = 3.63 A / 10 A = 36%，尚可接受；轻载时可能到 200%，模型失效。
② 带宽要远低于 fsw：平均模型丢掉了开关频率处的边带，模型只在 f < fsw/2 有效，实际上要更低。
③ CCM 假设：DCM 下拓扑结构变了（出现第三种状态），传函完全不同——DCM 的 Gvd 是单极点型，相位只有 −90°，比 CCM 好补偿但增益随负载变化剧烈。
④ 理想开关：不含导通损耗、开关损耗、死区。导通损耗可用 RDS(on) 和 DCR 串进去，死区则需要额外的描述函数建模。

1.5 采样与保持：连续世界和离散世界的桥

数字控制的本质是：被控对象是连续的，控制器是离散的，两者之间靠采样和保持连接。这个连接本身会引入相位滞后，是第 09 章的核心内容，这里先建立模型。

本章要带走的三句话。① 你的变换器有"大信号非线性"和"小信号 LTI"两套身份，控制理论只用第二套，用之前必须确认工作点。② 卷积告诉你输出的形状完全由 h(t)（等价于极点位置）决定，输入只负责缩放。③ 从 KVL/KCL 到 Gvd(s) 的六步里，第 3 步（平均）和第 5 步（丢掉二阶项）是两个必须记住的近似，它们定义了模型的适用边界。

稳定性是控制理论唯一"必须答对"的问题。答错的代价是硬件损坏。这一章给三种判稳工具，并说明各自什么时候用。

6.3 互补灵敏度 T：跟随与噪声的双刃剑

Tcl = T/(1+T) 是"参考到输出"的传递函数，也就是闭环带宽。它同时决定了两件事，而且方向相反：

频率段|Tcl|对"跟随参考/指令"对"高频噪声"
f ≪ fc≈ 1（0 dB）完美跟随——
f ≈ fc可能 > 1（有峰）响应快但有振铃噪声被放大
f ≫ fc≈ 1/|T| → 很小跟不动噪声被有效滤除

这就是"带宽不是越高越好"的数学原因。提高 fc 让跟随更快、扰动抑制更好，但同时让更多的高频噪声（开关噪声、ADC 量化噪声、采样抖动）进入输出。所以在数字电源里，fc 的上限往往不是稳定性决定的，而是噪声和量化决定的。

水床效应（waterbed effect）的实际后果。把低频扰动抑制做得越狠（fc 越高），fc 附近的 |S| 峰就必然越高。这解释了几个现场现象：

① 带宽推到极限后出现"低频很稳、中频振荡"：|S| 峰落在 fc 附近，表现为特定频率的持续振荡。
② 加滤波器"治标不治本"：在 |S| 峰的位置加陷波滤波器，只是把峰挪到别的频率。
③ RHP 零点让情况更糟：Boost / 反激的 RHP 零点会进一步限制 |S| 的可达形状，这是 Bode 积分在非最小相位系统上的推广结论。

7.4 关键纠错：绝对相位 vs 相位提升量

这是本页最重要的一张表。很多资料写"Type II 能提升 70° 相位"，让人误以为 Type II 能提供 +70° 的绝对相位。这是错的。Type II 结构是 一个零点 + 一个原点极点 + 一个高频极点，相位是：

∠Gc(jω) = −90° + arctan(ω/ωz) − arctan(ω/ωp)

当 ω → ∞ 时，arctan(ω/ωz) → 90°，arctan(ω/ωp) → 90°，两者相消，所以 绝对相位始终在 −90° 到 0° 之间。它能做的只是"把 −90° 拉回接近 0°"，永远到不了正值。

类型结构相对积分器的提升上限fc 处绝对相位的实用上限能对付多大的相位缺口
Type I1 个原点极点0°−90°（恒定）无
Type II原点极点 + 1 零 + 1 极+90°（理论）/ +70°（实用）≈ −20°（实用上限）被控对象在 fc 处不低于 −155°
Type III原点极点 + 2 零 + 2 极+180°（理论）/ +160°（实用）≈ +70°（实用上限）被控对象在 fc 处不低于 −250°

别把 −20° / +70° 当成数学硬边界。它们是留了余量的工程推荐值，不是结构的极限。真正的结构极限是：Type II 的绝对相位可以逼近 0°，但永远不能为正（零点相位 +90° 与高频极点相位 −90° 在高频相消）；Type III 理论上可以逼近 +90°。之所以推荐 −20° / +70°，是因为零极点不可能放在无穷远处，实际留约 20° 余量更稳妥。正确用法是：需要正相位 → Type II 一定不行（这是硬边界）；需要 −10° 这种"接近 0° 但仍为负"的值 → Type II 理论上可行，但余量很薄，要谨慎评估。

选型时怎么用这张表。设被控对象在 fc 处的相位为 φplant，目标相位裕度 PM。需要的补偿器绝对相位是：

∠Gc(fc) = −180° + PM − φplant − φdelay

把结果和上表最后一列比对：

  • 需要 −90°：Type I 就够
  • 需要 −90° ~ −20°：Type II（−20° 是推荐值，越接近 0° 余量越薄）
  • 需要 −20° ~ +70°：Type III（+70° 同样是推荐值，不是结构极限）
  • 需要 > +70°：余量不足，优先降低 fc 或改拓扑

本例的验证。fc = 20 kHz 时 φplant = −153.7°，φdelay = 0（模拟设计），目标 PM = 55°：需要 ∠Gc = −180° + 55° − (−153.7°) = +28.7°。这已经超过 Type II 的 −20° 上限，必须用 Type III。用 4 倍率配置（零点 5 kHz、极点 80 kHz）得到 +33.9°，PM 实际为 55° + (33.9 − 28.7) = 60.2°，与频域扫描结果完全一致。

7.6 抗积分饱和：非线性问题，但必须在这里讲

积分器 + 限幅 = 非线性系统，控制理论的线性工具全部失效。这是现场最常见的"莫名奇妙的不稳定"。

1
问题机制
启动时输出远低于设定值 → 误差很大 → 积分器持续累积到极大值（饱和）→ 占空比被限幅在最大值 → 输出冲过设定值后，积分器需要很长时间"退饱和"→ 输出持续过冲。
2
典型表现
启动过冲、负载突卸后长时间高压、保护恢复时的低频振荡（频率远低于 fc，通常几十到几百 Hz）。
3
解法一：钳位
给积分器状态加硬限幅（anti-windup clamp）。实现简单，但需要合理设置钳位值，且可能引入非线性抖动。
4
解法二：反算（back-calculation）
当输出被限幅时，把"期望输出 − 实际输出"的差值乘以 1/Tt 反馈回积分器输入，强制积分器跟踪。Tt 通常取 √(Ti·Td) 或 Ti。
5
解法三：条件积分
只在"输出未被限幅"时才允许积分。实现最简单，但在限幅边界附近可能抖动。
6
验证方法
必须做大信号测试：满载启动、空载启动、突加满载、突卸满载、限流恢复。小信号 Bode 扫频完全测不出这类问题。

一个容易忽略的细节。抗饱和只在"控制器输出被限幅"时起作用。但在多环系统里，内环限幅也会导致外环积分器饱和。例如峰值电流模式的电流环限幅（峰值电流限制）触发时，电压外环的积分器会持续累积。所以抗饱和逻辑必须穿透所有环路：内环被限幅时，必须通知外环停止积分。

状态空间相对于传递函数的三个优势。① 多输入多输出天然支持：Vin 扰动、负载扰动、参考可以同时作为输入，不用分别推导。② 初始条件天然支持：ẋ = Ax + Bu 可以直接从任意初值开始积分，适合分析启动、模式切换。③ 非线性扩展自然：把 ẋ = Ax + Bu 换成 ẋ = f(x,u) 就是非线性模型，可以在任意时刻线性化。

8.2 可控性与可观性

可控性矩阵：　𝒞 = [B　AB　A²B　…　An−1B]　　rank(𝒞) = n ⟺ 可控
可观性矩阵：　𝒪 = [C；CA；CA²；…；CAn−1]　　rank(𝒪) = n ⟺ 可观
概念含义电力电子里的实例
可控能否用输入把状态驱动到任意目标占空比能否控制 iL 和 vC——Buck 可以，所以可控
不可控存在某个状态无法被输入影响（可控性矩阵秩亏）——（注意：Middlebrook 的输入滤波器交互不是可控性问题，它是两个子系统之间的阻抗交互 / minor loop 稳定性问题）
可观能否从输出推算出所有状态只测 Vout 时，iL 能否推算出来？——可以通过模型推算，所以可观
不可观存在状态对输出无影响两个并联模块之间的环流（若只测总输出电流，环流不可观）

可观性的实用价值：电流观测器。如果只测输出电压，能不能知道电感电流？答案是能——只要系统可观。用 Luenberger 观测器：

ẋ̂ = Ax̂ + Bu + L(y − Cx̂) 　　L 为观测器增益，误差动态为 (A − LC)，按需要配置极点

这就是"无电流传感器电流模式控制"（sensorless current mode）的理论基础。工程上要注意：观测器的收敛速度必须快于环路带宽（通常取 3~5 倍），但又不能太快否则会放大噪声。而且观测器对模型误差敏感——L、C 偏差 20% 时，观测的电流也会有相应误差。

8.3 极点配置与状态反馈

如果所有状态都可测（或可观测），就可以用状态反馈 u = −Kx 直接配置闭环极点。对二阶系统，闭环特征多项式是 s² + (k₁/L − 1/(RC))s + …，可以任意配置。

分离原理（Separation Principle）的适用边界。它保证"观测器 + 状态反馈"的闭环极点是"观测器极点 ∪ 控制器极点"，两者可以独立设计。但这条定理只在 LTI 系统上严格成立。实际系统有饱和、量化、延时，观测器可能因为模型误差而发散。所以工程上：观测器极点不能配置得太快（噪声放大），也不能太慢（相位滞后）。

8.4 电流模式控制的状态空间视角

峰值电流模式控制看起来是"模拟电路技巧"，但用状态空间看，它实际上是一个内环状态反馈。

视角描述得到的结论
传统视角电流环把 iL 强制跟随参考，外环变成"电流源驱动电容"被控对象从 LC 双极点变成单极点（1/sC）
状态空间视角内环实现了对状态 iL 的反馈，把 (A, B) 系统的 iL 动态"内化"降阶：n 阶系统变成 n−1 阶

为什么 D > 0.5 会次谐波振荡。从状态空间看：峰值电流模式在每个周期开始时刻采样 iL，然后等它涨到参考值就关断。扰动 Δi 在下个周期会变成 −(D/(1−D))·Δi。当 D > 0.5 时，|D/(1−D)| > 1，扰动被放大——极点跑出单位圆，出现 fsw/2 的次谐波振荡。斜坡补偿的本质是改变这个放大倍数，把它拉回 1 以内。这与第 09 章的离散系统稳定性是同一个数学结构。

9.6 DPWM 分辨率与极限环

数字 PWM 的占空比是量化的，最小步长 ΔD = 1/(2N − 1)。这个量化台阶会造成一个"死区"：当误差小到不足以让占空比改变一格时，环路就"看不见"误差了，积分器继续累积直到跨过一格，然后又反向——形成极限环（limit cycle）。

DPWM 位数ΔD = 1/(2N−1)输出端 ΔVo = Vin·ΔDADC 端 H·ΔVo与 ADC LSB（1.000 mV）比较
8 bit0.003921647.06 mV11.41 mV远大于 LSB → 明显极限环
9 bit0.001956923.48 mV5.69 mV大于 LSB → 有极限环
10 bit0.000977511.73 mV2.84 mV大于 LSB → 有极限环
11 bit0.00048855.86 mV1.42 mV略大于 LSB → 轻微
12 bit0.00024422.93 mV0.710 mV小于 LSB → 基本消除

判据：DPWM 的量化台阶折算到 ADC 输入端后，必须细于 ADC 的 LSB。注意两个量不在同一节点：ΔVo = Vin·ΔD 是输出端的电压台阶，而 ADC 的 LSB 是反馈输入端的电压，不能直接比。必须统一到同一个域，即 H·Vin·ΔD < LSB（本例 H = 0.2424）。本例 ADC 是 12 bit、量程 0~4.096 V，LSB = 1.000 mV；DPWM 需要至少 12 bit（ADC 端台阶 0.710 mV）才能让量化台阶小于 ADC 分辨率。如果 DPWM 只有 10 bit，ADC 端会看到 2.84 mV 的台阶——看起来很小，但它是低频的（几 kHz），会干扰下游负载，而且用示波器看是"输出在缓慢摆动"。

两个实用的解决手段：① 提高 DPWM 有效位数（用高分辨率 PWM 外设、或者 dithering / 抖动技术）；② 在控制器里加一个小的死区或迟滞，主动"放弃"小于量化台阶的调节（代价是静态精度）。

9.7 采样时刻与更新时刻的工程安排

1
确定采样触发源
必须由 PWM 定时器触发（不能自由跑）。触发点通常选三角载波的峰顶或谷底，此时 iL 等于其平均值，天然滤掉开关纹波。
2
安排 ADC 转换时间
ADC 采样保持 + 转换需要时间（典型 0.5~1 µs）。如果转换不能在下一个周期前完成，就要用"流水线"：本周期用上周期的采样值计算。
3
计算并写入比较寄存器
尽量在下一个 PWM 周期开始前完成。使用"影子寄存器 + 周期边界更新"避免占空比在周期中间被改写（会产生脉冲宽度错误）。
4
核对总延时
Td = 采样点到更新点的实际时间。用示波器测量：注入一个占空比阶跃，观察实际输出响应的延迟。
5
按实际 Td 重算 fc
用 φdelay = −540°·(fc/fs)·(Td/1.5Ts) 修正，重新校核 PM。
6
考虑双沿更新
如果 fs 已经不能提高而 fc 又需要更大，可改用双沿（对称）更新：在本例这种"峰顶采样 + 一周期计算 + 周期边界更新"的时序假设下，等效更新延时可从约 1.5Ts 降到约 0.5Ts。代价是需要更高的计算吞吐。实际能降到多少取决于采样点、ISR 延迟、计算耗时与 shadow register 装载时刻，必须按具体 MCU 外设时序核实。

本章要带走的三句话。① 采样必须与 PWM 同步，采样点选在纹波峰顶/谷底，否则纹波混叠成低频振荡。② 离散化方法（Tustin / 后向欧拉 / MPZ）在 fc ≪ fs/2 时几乎不影响结果，真正的杀手是采样—更新延时 Td——本例时序下 Td ≈ 1.5Ts，速算公式 φ = −540°·(fc/fs)。实际项目必须按 ADC 触发时刻、计算完成时间和 PWM shadow-load 时刻建立自己的延时预算。③ DPWM 分辨率必须细于 ADC LSB，否则出现低频极限环。

工程含义：饱和本身不会导致不稳定，但会改变有效增益，可能把工作点推到 |T| = 1 且相位 −180° 的位置。所以在设计时，除了额定工作点的 PM，还要检查"增益下降 6 dB 后的 PM"——这就是增益裕度 GM 的意义之一。

10.4 恒功率负载与负电阻

负电阻不是一个比喻，它字面意思就是"电压升高时电流减少"。对 P = V·I 恒定的负载，dI/dV = −P/V² < 0，所以增量电阻 Rinc = dV/dI = −V²/P 是负的。

负载类型增量电阻阻尼贡献典型场景
纯电阻负载+R（正）正阻尼，帮助稳定简单测试
恒流负载∞（不贡献）无阻尼电子负载 CC 模式
恒功率负载−V²/P（负）负阻尼，破坏稳定DC-DC 后级、电机驱动器
恒压负载0无阻尼——

负电阻造成的两个具体后果。① LC 谐振的阻尼被抵消：输出 LC 或输入 LC 的谐振峰被抬高，可能变成持续振荡。② 环路 PM 降低：在负电阻显著的低频段，被控对象的等效阻尼下降，相位在谐振附近跌得更深。

工程应对：① 在输出端加 RC 阻尼支路（snubber）；② 用有源阻尼（把输出电容电流或电感电流反馈进控制环，虚拟增加阻尼）；③ 保证最小负载电流（让正电阻负载占主导）；④ 降低环路带宽避开谐振区。

11.4 实测方法：怎么真的测出环路

1
选注入点
必须选在"环路增益经过的、且信号单方向流动"的位置。典型选择：反馈分压点（注入小电阻）、误差放大器输入、或者补偿器输出。不要选在低阻抗节点（如输出电容两端），否则注入不进去。
2
注入方式
用隔离变压器（或光耦）注入正弦小信号，幅值足够小（典型 10~50 mV），保证系统仍在线性区。幅值太大测出来的 PM 会偏小（被饱和"吃掉"）。
3
扫频范围
从 10 Hz 扫到 fsw/2。低频要扫到足够低以确认积分器的 −20 dB/dec；高频要扫到 fsw/2 以看清高频衰减和延时效应。
4
测增益和相位
环路分析仪测量注入点前后的信号比（A/B 通道），直接得到 T(jω)。注意：注入点两侧的阻抗比会引入误差，阻抗比越接近 1 误差越小。
5
读出 fc、PM、GM
在 0 dB 交点读相位 → PM = 180° + ∠T；在 −180° 相位点读增益 → GM = −20log|T|。
6
多工况重复
必须在多个工作点各扫一遍：额定负载 / 10% 负载 / 空载 / 最低 Vin / 最高 Vin。把每一条曲线的 PM 都记下来，取最小值作为设计裕度。

实测的五个陷阱。① 注入幅值太大：系统进入非线性区，PM 读数偏小 10°~20°。② 注入点选错：测到的是局部传递函数，不是环路增益。③ 未考虑输出纹波：开关纹波进入分析仪的相位检测，读数抖动。④ 测量时加了假负载：改变了 Q 和谐振峰，测出来的不是真实工况。⑤ 用示波器做阶跃响应代替扫频：只能定性看振铃，不能定量读 PM。

14十个常见误区

  1. "Type II 能提升 70° 相位，所以够用。"那 70° 是相对于积分器 −90° 的提升量，不是绝对相位。Type II 在 fc 处的绝对相位上限约 −20°。选型必须拿"需要的绝对相位"去比。（第 7.4 节）
  2. "环路增益 T = Gc·Gvd·H。"漏了 PWM 调制器增益 Fm = 1/Vramp。Vramp 从 1 V 变到 2.5 V，环路增益直接掉 8 dB，fc 降 2.5 倍。（第 11.1 节）
  3. "模拟调通了，直接搬进 DSP 就行。"数字实现会引入采样—更新延时，本例时序下 Td ≈ 1.5Ts = 5 µs。fc = 20 kHz 时这 5 µs 就是 −36°，PM 从 60.19° 掉到 24.19°。（第 12.8 节）
  4. "PM 不够就降 fc。"降 fc 会让瞬态响应变慢。本例中 fc 从 20 kHz 降到 8 kHz，PM 恢复到 52°，但负载阶跃偏差从 44 mV 涨到 122 mV，超出 100 mV 规格。真正的解法是减小 Td。（第 12.9 节）
  5. "只按额定工作点设计就够了。"轻载时 Q 从 3.84 升到 9.51（谐振峰从 +11.7 dB 到 +19.6 dB）；Boost 类拓扑在最低 Vin（D 最大）时 RHP 零点最低。必须按最恶劣组合设计。（第 2.6、10.1 节）
  6. "看 PM 就知道稳不稳。"PM 只反映穿越点附近的情况。|S|max 更敏感：本例方案 B 的 PM 还有 24°（看起来不算灾难），但 |S|max = 2.797（8.9 dB），意味着扰动被放大 2.8 倍。（第 6.2 节）
  7. "输出电容按纹波选就行。"瞬态指标往往比纹波指标更苛刻。本例按纹波只需要几十 µF，按 100 mV 瞬态指标需要 680 µF。（第 12.3 节）
  8. "穿越斜率无所谓，只要 PM 够。"−40 dB/dec 穿越时相位预算基本耗尽，工程上极难稳定——但要注意这是经验直觉：Bode 增益—相位是全频域关系，局部斜率不唯一决定相位，判据应以完整环路相位计算为准。−20 dB/dec 才有约 90° 的相位预算。（第 4.2 节）
  9. "Bode 图看起来没问题就一定没问题。"三类问题在传统注入点测得的主控制环 Bode 图上看不到：① 输入滤波器交互（Middlebrook）；② 恒功率负载的负电阻；③ 积分器饱和造成的低频振荡。这三类必须单独验证——不是说 Bode / Nyquist 本身无能，用阻抗 minor-loop 照样能画出对应的 Bode / Nyquist 把它们看出来。（第 10 章）
  10. "DPWM 位数够高就行，分辨率不重要。"判据是 DPWM 的量化台阶折算到 ADC 输入端后必须细于 ADC 的 LSB，即 H·Vin·ΔD < LSB——不能拿输出端的 Vin·ΔD 直接去和 ADC 的 LSB 比（两者差 13%）。本例 ADC 12 bit（LSB = 1.000 mV），DPWM 需要 ≥ 12 bit（ADC 端台阶 0.710 mV）；只有 10 bit 时 ADC 端会看到 2.84 mV 的低频极限环。（第 9.6 节）

16自测：检查你是否真的掌握了

1. 被控对象在 fc 处相位 −180°，要求 PM = 60°，需要什么类型的补偿器？为什么不能用 Type II？

需要补偿器在 fc 处提供 ∠Gc = −180° + 60° − (−180°) = +60° 的绝对相位。Type II 的绝对相位实用上限约 −20°（它的相位恒在 −90° 到 0° 之间，因为零点相位 +90° 与高频极点相位 −90° 在高频相消），无法达到 +60°。Type III 有两个零点，理论绝对相位上限 +90°（实用约 +70°），可以做到。
关键：不能用"Type II 能提升 70°"这种说法来选型——那 70° 是相对积分器 −90° 的提升量。

2. 一个数字电源，fsw = 200 kHz，单沿更新，想把 fc 设在 40 kHz。这个想法可行吗？

先算延时相位：Td = 1.5Ts = 7.5 µs，φdelay = −540° × 40/200 = −108°。
即使被控对象在 fc 处相位是 −90°（理想单极点），补偿器绝对相位最多 +70°，总相位 = −90° + 70° − 108° = −128°，PM = 52°——听起来还行。但实际被控对象在 40 kHz 处相位通常是 −150° 以下，那么总相位 = −150° + 70° − 108° = −188°，已经不稳定。
结论：不可行。fc 应降到 fs/15 ~ fs/10，即 13~20 kHz。或者改用双沿更新把 Td 降到 2.5 µs（延时相位 −36°）。

3. 一个 Buck 用纯比例控制，Kp = 10，Vin = 12 V，Vramp = 1 V，Vref = 0.8 V，Vout = 3.3 V。直流静差是多少？怎么消除？

H = Vref/Vout = 0.8/3.3 = 0.242424，Fm = 1。
T(0) = Kp · Gvd(0) · Fm · H = 10 × 12 × 1 × 0.242424 = 29.09。
静差 = 1/(1 + T(0)) = 1/30.09 = 3.32%，折合输出偏差 = 3.32% × 3.3 V = 109.7 mV。
要消除静差必须引入积分器（Type I/II/III 都含原点极点）。但注意：把 Kp 提到 50 只能把静差压到 0.68%（22.5 mV），仍然做不到高精度——这就是积分器不可替代的原因。

4. 为什么轻载比满载更容易振荡？用数字说明。

因为 Q = 1/[ω₀(L/R + rCC)]，而 R = Vout/Iout。轻载时 R 增大，(L/R) 项减小，Q 增大。
本例（C = 680 µF，L = 2.2 µH，ESR = 5 mΩ，ω₀ = 25 840 rad/s）：
· 满载（R = 0.33 Ω）：Q = 1/[25840 × (6.667×10⁻⁶ + 3.4×10⁻⁶)] = 3.84（+11.7 dB）
· 10% 负载（R = 3.3 Ω）：Q = 1/[25840 × (6.667×10⁻⁷ + 3.4×10⁻⁶)] = 9.51（+19.6 dB）
· 空载极限：Q → 1/(ω₀·rCC) = 1/(25840 × 3.4×10⁻⁶) = 11.4（+21.1 dB）
谐振峰从 +11.7 dB 涨到 +21 dB，意味着在 f₀ = 4.11 kHz 附近环路增益多出 9.4 dB。如果 fc 附近的相位本来就不够，这个峰会直接把系统推向不稳定。所以必须按轻载（或 10% 负载）校核。

5. 什么是"穿越斜率 −20 dB/dec"？为什么它比 PM 更根本？

穿越斜率是 |T| 曲线在 0 dB 交点处的斜率。对于最小相位系统，Bode 增益—相位关系给出一个近似：斜率 −20 dB/dec 大致对应 −90° 相位，−40 dB/dec 大致对应 −180°。
它比 PM 更有指导性，是因为：如果穿越附近长期呈 −40 dB/dec，说明两个极点占主导，相位裕度会非常差，单靠调增益救不回来。而斜率 −20 dB/dec 时你还有约 90° 的相位预算，可以从中"分"出 50~60° 的 PM。
要强调：Bode 的增益—相位关系是全频域的积分关系，局部斜率不能唯一决定该点相位，所以这是工程直觉而非定理，最终必须用完整环路相位计算（或实测）确认。
所以"环路整形"的第一目标不是"提高 PM"，而是"让穿越斜率达到 −20 dB/dec"。

6. 一个 Boost 变换器，R = 12 Ω，D = 0.5，L = 22 µH。RHP 零点在哪？fc 能取多少？

Boost CCM 的 RHP 零点 ωrhpz = R(1−D)²/L = 12 × 0.25/22×10⁻⁶ = 136.4 krad/s，即 frhpz = 136.4×10³/(2π) = 21.7 kHz。
工程取 fc ≤ frhpz/3 ~ /5，即 4.3 ~ 7.2 kHz。
注意：这个 frhpz 是按 D = 0.5 算的。如果 Vin 变化使 D 增大到 0.7，frhpz = 12 × 0.09/(2π × 22×10⁻⁶) = 1.08/(1.382×10⁻⁴) = 7.8 kHz，可用的 fc 只剩 1.6~2.6 kHz。所以 Boost 的 fc 必须按最大 D（最低 Vin）工作点来确定。

7. 环路分析仪实测 PM = 35°，但设计算出来是 58°。列出至少五个可能原因和排查方法。

① 漏掉 Fm 或 H：核对 Vramp 实际值和分压电阻，这会改变 fc 的位置，从而改变读到的 PM。
② 漏掉采样延时：核对实际 Td（用占空比阶跃测试）。
③ 注入幅值太大：系统进入非线性区。把注入幅值减小一半重测，如果 PM 变大就说明是这个原因。
④ 工作点不同：实测时可能处于轻载（Q 高）或低 Vin（D 大）状态。
⑤ 注入点选错：测到的是局部传函而不是环路增益。检查注入点是否在"信号单方向流动"的位置。
⑥ 寄生参数：运放 GBW 限制、PCB 耦合电容、电感寄生电容。
⑦ 元件偏差：补偿器 RC 容差 5~10%，L/C 偏差 20%。

8. 为什么输入滤波器会引起低频振荡？为什么环路 Bode 图上看不到？

因为变换器是恒功率负载：Vin 下降时输入电流上升，所以增量输入阻抗 Zin = −Vin²/Pin 是负的。负电阻与 EMI 滤波器的 Lf、Cf 组成谐振回路时，阻尼被抵消（甚至变成负阻尼）。
Middlebrook 判据要求 |Zout,filter| ≪ |Zin,converter|（差 6 dB 以上）——这是一个好用的保守充分设计规则。两者幅值相等时进入高风险区（负电阻把阻尼抵消掉），但是否真的失稳还要看阻抗比 Zout/Zin 的相位与 Nyquist 条件。
环路 Bode 图上看不到，是因为它是子系统之间的交互：环路分析仪测的是"从补偿器输入到输出的单环路"，不包含源与滤波器之间的阻抗交互。而且这个振荡频率通常远低于 fc（几百 Hz ~ 几 kHz）。
验证方法：在源与滤波器之间注入扰动测阻抗比；或者做输入电压阶跃测试看是否出现低频振铃。

9. 某数字电源出现 3 kHz 左右的低频振荡，幅值很小（约 5 mV），但一直不消失。最可能是什么问题？

最可能是 DPWM 量化造成的极限环。
判据：DPWM 的量化台阶折算到 ADC 输入端后必须小于 ADC 的 LSB，即 H·Vin·ΔD < LSB。本例中 ADC 12 bit、量程 0~4.096 V，LSB = 1.000 mV，H = 0.2424。如果 DPWM 只有 10 bit，ΔD = 0.0009775，输出端 ΔVo = 12 × 0.0009775 = 11.73 mV，折算到 ADC 端 H·ΔVo = 2.84 mV，大于 ADC 的 LSB。
后果：误差小于量化台阶时环路"看不见"，积分器继续累积直到跨过一格，然后反向——形成低频极限环。
解决：① 提高 DPWM 有效位数（≥ 12 bit）；② 用 dithering（抖动）技术；③ 在控制器里加死区或迟滞（代价是静态精度）。
注意排除：如果是 |S| 峰造成的振荡，频率应该在 fc 附近（几 kHz ~ 几十 kHz）且幅值大得多；3 kHz 且幅值极小、频率与 fs 无关，是量化的典型特征。

10. 客户要求负载从 10 A 跳到 5 A 时输出偏差 ≤ 50 mV。fsw = 300 kHz，L = 2.2 µH，ESR = 5 mΩ。给出方案。

ΔI = 5 A，ESR 台阶 = 5 × 5 mΩ = 25 mV，占规格的一半。留给电容的只有 25 mV。
纯反馈方案：ΔV ≈ ΔI·[rC + 1/(2πfcC)]。要求 50 mV，则 1/(2πfcC) ≤ 5 mV，即 fc·C ≥ 5/(2π × 0.005) = 159.2。
· 若 fc = 20 kHz → C ≥ 7.96 mF（不可能）
· 若 fc = 50 kHz → C ≥ 3.18 mF（且 fc = fsw/6 数字实现做不到）
结论：纯反馈方案不可行。
必须用负载电流前馈：ΔV ≈ ΔI·[rC + Ts/C]。取 C = 680 µF，Ts = 3.33 µs：ΔV ≈ 5 × (5 mΩ + 3.33µ/680µ) = 5 × (5 + 4.90) = 49.5 mV，刚好满足。
若留余量，把 C 提到 1000 µF：ΔV ≈ 5 × (5 + 3.33) = 41.7 mV。
代价：需要负载电流检测（可用输出电流采样或输入电流反推），以及前馈增益的精度校准。
